# Java Basics Practice

Small Java programs for the core basics: variables, loops, methods, strings, arrays, OOP (encapsulation, inheritance, overloading) and exception handling. Each program has a saved output.

**Note:** These are beginner practice programs. I am learning Java and the Selenium course is still ongoing, so there is no automation framework in this repo yet.

## Programs

| Program | Topic |
|---|---|
| `HelloWorld` | First program, `println` |
| `Variables` | Data types: String, int, double, char, boolean |
| `EvenOdd` | if / else, modulus, for-each loop |
| `Calculator` | Methods with return values, divide by zero check |
| `Factorial` | for loop, long |
| `Fibonacci` | Loop with swapping values |
| `VowelCounter` | Strings, char, toCharArray |
| `PalindromeCheck` | StringBuilder reverse, boolean method |
| `ArrayMaxMin` | Arrays, max / min / average |
| `Encapsulation` | private fields, getters and setters, simple validation |
| `Inheritance` | `extends`, reusing a parent class method |
| `MethodOverloading` | Same method name, different parameters |
| `ExceptionHandling` | try / catch / finally |

Sample output for each is in the `outputs/` folder.

## How to run

**Eclipse:** File > Import > General > Existing Projects, or create a Java project and copy `src/org` into its `src` folder. Right click a file > Run As > Java Application.

**Command line (Java 11 or newer):**

```
java src/org/javaprograms/HelloWorld.java
```

All 13 programs were compiled and run with Java 11 before uploading, and the `outputs/` files are the real output.
